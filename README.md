# Django Portfolio

A personal portfolio website built with Django.

This project is being developed as a practical project to learn and practice Django concepts.

## About the Project

This portfolio website contains different sections for introducing myself, my skills, projects, and contact information.

The project is built with multiple Django apps to practice Django's project structure and core concepts.

## Pages

- Home
- About
- Skills
- Projects
- Contact

## Django Apps

The project is divided into separate apps:

- `home` - Home page
- `about` - About me
- `skills` - Skills and technologies
- `projects` - Portfolio projects
- `contact` - Contact information and form

## Technologies

- HTML
